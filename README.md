# Agent skills

Personal skills for learning technical concepts, understanding code, and getting project work done.

- [learn-concept](skills/learn-concept/SKILL.md): Understand an unfamiliar idea through a worked example.
- [practice-concept](skills/practice-concept/SKILL.md): Try exercises or write the core code yourself, with hints and feedback.
- [learn-codebase](skills/learn-codebase/SKILL.md): Follow a source-linked route through a repository or feature, one stop at a time.
- [start-project](skills/start-project/SKILL.md): Turn a rough idea into a small, verifiable first result.
- [do-project-task](skills/do-project-task/SKILL.md): Complete a defined fix, feature, or refactor in an existing project and check the result.
